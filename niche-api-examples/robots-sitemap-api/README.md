# Robots.txt & Sitemap Checker API

도메인 하나를 주면 robots.txt 크롤링 규칙과 sitemap.xml 상태(URL 개수 등)를 함께 점검합니다.

**상태: 마켓플레이스 등록 준비 중입니다.** RapidAPI/Zyla/API.Market/FireAPI에 게시되면 이 문서를
실제 호출 가능한 예제로 갱신합니다. 요청/응답 형태는 이미 확정돼 있습니다:

```
GET /v1/check?domain=example.com
```
