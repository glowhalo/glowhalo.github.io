# CORS Policy Checker API

URL(과 선택적 Origin)을 주면 서버의 CORS 응답 헤더를 simple request·preflight 둘 다로 점검해 흔한 오설정을 표시합니다.

**상태: 마켓플레이스 등록 준비 중입니다.** RapidAPI/Zyla/API.Market/FireAPI에 게시되면 이 문서를
실제 호출 가능한 예제로 갱신합니다. 요청/응답 형태는 이미 확정돼 있습니다:

```
GET /v1/check?url=https://api.example.com&origin=https://myapp.com
```
